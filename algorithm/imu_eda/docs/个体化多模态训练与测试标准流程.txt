是非钟：个体化多模态数据训练、校准与测试标准流程（V1.0）
================================================================

0. 本文用途与适用范围
--------------------
本文是后续重建 IMU、BVP、EDA 三层算法时唯一采用的实验协议。它解决三个问题：
1) 不把同一个人的相邻滑动窗口同时用于调参与测试；
2) 允许真实产品中的“先校准、后少量反馈”，但不把校准/反馈数据混进最终测试；
3) 让最终报告的指标尽量接近新用户实际佩戴后的表现。

本协议把系统定位为“事件触发 + 运动干扰过滤 + 生理信号确认”，不把任何单一生理指标
表述为医学诊断或绝对的情绪判断。


1. 总体数据结构：以会话和连续时间块为最小单位
------------------------------------------------
不得把“单个滑动窗口”当作数据集的原始样本单位。原始单位应为：

  participant_id / recording_session_id / chronological_block_id / time_start / time_end /
  imu / bvp / eda / label / label_source / sensor_quality / notes

每次录制必须有独立 session_id；至少记录日期、佩戴手、表带松紧、采样率、是否运动、
是否有明显传感器接触不良，以及标签由谁确认。

连续时间块建议最短 30 秒。所有训练、反馈和测试的切分，都必须先按“连续时间块”完成，
再在各自块内部切滑动窗口。不得先滑窗再随机切分。


2. 三层任务、标签与采样
-------------------------

2.1 IMU：运动干扰过滤层
目标：判断某段腕部运动是否足以解释后续心率/血氧/EDA 波动，决定是否暂缓生理信号判断。
它不负责识别情绪，也不负责识别“拍桌子/指人”等未来手势。

建议改为三档标签，而不是简单二分类：
  A. 允许（quiet / common low motion）：静坐、打字、拿水杯、普通挥手、日常手部操作；
  B. 边界（mild activity）：正常走路、上下楼、轻家务；
  C. 过滤（high motion）：跑步、快速甩腕、跳跃、剧烈运动、持续高频抖动。

产品策略：A 进入生理层；C 直接过滤；B 由保守阈值或连续观测决定（例如暂停生理判定，
待连续低活动后恢复）。如此避免把“走路”硬塞进安静或剧烈任一类别。

每位成员最低建议采集：A/B/C 各至少 3 个独立时间块，每块 60-120 秒；不同日或重新佩戴
至少增加 1 个会话。对项目特定的拍桌子、指人等，必须自行采集标签，不使用公开 HAR 数据
替代最终结论。

2.2 BVP + EDA：生理确认层
目标：在 IMU/声音触发且运动层允许后，判断“相对该用户正常静息状态是否存在明显生理
唤醒变化”。标签建议是 baseline / event-confirmed 两类；不要将其写成临床“情绪诊断”。

个人静息基线只包含稳定、低活动段：静坐、自然呼吸、轻微手部操作；不能把走路、剧烈运动
放进 BVP/EDA 的静息基线。IMU 的日常动作校准与 BVP/EDA 的静息基线是两套不同数据，
不得混用。

建议每人每个会话至少：
  - 静息基线 2 分钟；
  - 已确认事件/压力片段至少 3 个独立块；
  - 与事件无关但可能造成干扰的低活动片段至少 3 个独立块。


3. 窗口化规则
--------------
训练时允许滑动窗口提高信号利用率，但不能把它误称为等量独立样本。

  IMU：2 秒窗口、1 秒步长；
  BVP/EDA：5 秒窗口、1 秒步长（沿用现有端侧目标）；
  测试汇报：除逐窗指标外，增加不重叠窗口或按 30 秒块汇总的指标；
  切分隔离带：不同数据用途的相邻时间块之间，至少留一个完整窗口长度：IMU >=2 秒，
              BVP/EDA >=5 秒。隔离带内窗口直接丢弃，不用于任何用途。

窗口标签规则必须预先写明，例如：窗口内目标标签占比 >=90% 才保留；混合状态或传感器质量
不合格窗口剔除，并在报告中统计剔除比例。


4. 标准个体化训练与盲测协议
--------------------------------

阶段 0：固定全局训练集（source subjects）
  - 选择若干完整受试者作为全局训练对象，例如 S2-S11；
  - 所有预处理参数、特征定义、逻辑回归权重、融合结构只由这些人训练；
  - 需使用“按受试者留出”的内部验证选择全局超参数，不能随机拆分所有窗口；
  - 输出冻结全局模型：特征顺序、全局统计量、BVP/EDA 模态权重、初始阈值、版本号。

阶段 1：新用户无监督/低成本校准（calibration）
  - 新用户录制开始时先完成固定的 2 分钟校准流程；
  - IMU 使用 A 类日常低运动动作的组合；BVP/EDA 仅使用稳定静息片段；
  - 使用稳健统计量 median（中位数）和 MAD（中位数绝对偏差）或截尾均值/标准差，
    不应只使用普通均值，因为偶发大动作会污染个人中心；
  - 校准数据从此以后永久排除，不进入反馈指标和盲测指标；
  - 仅可更新个人中心、个人尺度、佩戴质量阈值，不更新全局分类器权重。

阶段 2：有标签少量反馈（feedback adaptation）
  - 使用校准之后、与盲测块时间上隔离的独立块；
  - 推荐至少包含“困难负样本”和“目标正样本”，不能只用大量静息样本；
  - 全局分类器权重冻结；仅可在反馈集上选择：个人对齐强度、个人阈值、BVP/EDA 决策权重、
    或 IMU 的 B 类策略；
  - 将所有候选参数及选择准则事先列出。示例：在 precision >= 90% 约束下最大化 F1；
    对 IMU 过滤层可在 motion recall >= 90% 约束下最大化 precision；
  - 不允许根据盲测结果回头修改任何阈值。

阶段 3：空白盲测（personalized blind test）
  - 使用此前从未参与校准、训练、参数选择的完整后续时间块；
  - 最理想：不同录制会话或不同日期、重新佩戴后的数据；
  - 最低可接受：同一次会话的更后时间段，必须在报告中标为“会话内时间盲测”，不能称为
    “跨会话独立测试”；
  - 最终报告必须逐受试者列出样本时长、块数、正负样本数、混淆矩阵、Precision、Recall、
    F1、Balanced Accuracy（类别不均衡时）以及触发延迟。


5. 防泄漏检查清单（每次运行前逐项勾选）
------------------------------------------------
[ ] 先按 participant/session/time block 切分，再切滑窗。
[ ] 同一原始采样点不可能同时出现在训练、校准、反馈、测试中。
[ ] 校准时间段完全从评价集合排除（test-exclusive baseline）。
[ ] 全局特征标准化参数只由 source subjects 估计。
[ ] 新用户个人中心/尺度只由该用户校准块估计。
[ ] 模态权重、个人阈值、平滑参数只由反馈块选择。
[ ] 盲测块没有被用于观察指标后重新选阈值。
[ ] 如果有多日数据，最终盲测优先使用未参与任何步骤的新会话。
[ ] 每个结果文件均保存 random seed、数据版本、参与者列表、时间块边界及模型版本。


6. 指标与部署规则
-------------------
不要只报告 Accuracy。对于“尽量减少误报警”的生理确认层，重点报告 Precision、FP；
对于“不要漏掉运动干扰”的 IMU 层，重点报告 Recall、FN；两者都报告 F1、混淆矩阵与
逐人结果。类别比例不同的受试者之间，额外报告 Balanced Accuracy 或 Macro-F1。

部署时不要把单个窗口直接等同于最终事件：
  - IMU 过滤：例如最近 3 个窗口中 >=2 个判为 C，才暂停生理层；连续 2 个 A 后恢复；
  - 生理确认：IMU 允许且最近若干 BVP/EDA 窗口满足阈值，才生成一次“疑似事件”；
  - 同一事件设置冷却时间，避免连续通知。

所有“窗口数量”均须同时提供真实独立录制时长与时间块数。重叠滑窗数只能写为“处理窗口数”，
不得当作独立样本量或直接与独立样本统计检验等同。


7. 对现有实验结果的处理原则
------------------------------
已有 WESAD BVP/EDA 与 PAMAP2 IMU 结果保留为“原型探索结果”，用于证明流水线和端侧参数
导出可运行；后续按本协议重做后，才作为答辩中正式展示的个体化性能。

此前“按受试者留出”的全局训练结论仍有参考价值。此前同会话前半段反馈、后半段测试的结果
应改称“会话内时间盲测”，不再称为完全独立测试。若历史脚本曾先滑窗再随机切分，则该结果
只保留为调试结果，不用于最终性能声明。


8. 建议的最终答辩表述
------------------------
“系统首先利用腕部 IMU 识别并过滤剧烈运动引起的生理波动；在低活动条件下，调用冻结的
BVP-EDA 全局确认模型。首次使用时，用户完成短时个人基线校准；少量确认反馈仅用于调整
个人尺度与决策阈值，不重新训练全局分类器。最终指标来自严格隔离的后续时间块/新会话，
以评估真实佩戴条件下的个体化泛化能力。”

附：本项目的工程取舍
--------------------
本项目保持逻辑回归和决策级融合，不引入神经网络。上述标准流程不要求复杂模型；它优先保证
数据边界正确、模型参数可解释、黄山派端侧可以以少量参数完成个人校准。
