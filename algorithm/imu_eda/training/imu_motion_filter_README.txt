是非钟：腕部 IMU 运动干扰过滤层

用途
----
本模块不是情绪分类器。它位于心率/血氧（若硬件接入）/皮电判断之前：
当腕部 IMU 显示用户正处于跑步、骑车、北欧走、踢球或跳绳等剧烈/持续
运动状态时，暂不输出由生理信号触发的“疑似情绪激动”结果；低活动/安静状态才
进入后续的生理信号检测。

本轮数据与训练设计
------------------
数据集：PAMAP2 Protocol，9 位受试者，腕部（hand）三轴加速度计和陀螺仪，100 Hz。
窗口：2 秒窗口、1 秒滑动步长。
特征：加速度模长和陀螺仪模长的均值、波动、峰值、能量及加速度变化率。走路、上下楼
不在本轮二分类的任一类中，避免将边界活动错误地强行定义为“剧烈运动”。
模型：标准化 + 平衡逻辑回归；端侧参数会导出到 output/imu_motion_gate_params.h。
个体化验证：S101-S106 用于训练全局逻辑回归权重并冻结。对未训练者 S107、S108，先从
低活动窗口中拼出 120 秒个人静息基线；后续样本按类别均衡分为 50%“带反馈调阈值”和
50%“空白盲测”。个人阶段只能更新基线中心、基线波动尺度和阈值，不更新全局分类器权重。
空白盲测从未用于校准或调参。

为避免“个体化必然更好”的不可靠假设，反馈阶段还会选择 0%、25%、50%、75%、100% 的
个人基线对齐强度；若完整对齐使反馈集表现变差，则保留较弱对齐或直接保留全局特征空间。

运行
----
python train_pamap2_motion_filter.py

结果文件
--------
output/metrics.json              训练、验证、独立测试和逐人指标
output/imu_motion_gate.pkl       Python 端模型
output/imu_motion_gate_params.h  黄山派 C 端可嵌入的冻结参数

答辩表述建议
------------
“在生理信号判定前设置了独立的腕部 IMU 运动干扰过滤层，过滤剧烈或持续运动造成的
心率/血氧波动；仅在低活动状态下启动生理信号检测。该层不声称从动作识别情绪。”

注意
----
PAMAP2 的‘手腕’IMU 是公开数据的替代验证来源。最终阈值仍要在实际佩戴方向、采样率
和传感器量程下用本组数据复标定；它不能证明对‘拍桌子/指人’等细粒度动作的识别能力。
