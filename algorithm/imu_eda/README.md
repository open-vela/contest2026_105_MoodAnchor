# IMU + EDA 算法材料

本目录包含训练、评估、个体化反馈、端侧模型导出和小型指标结果；不包含 WESAD、PAMAP2 或 PhysioNet 原始数据集。

- `training/`：训练、个体化和模型导出脚本。
- `evaluation/`：冻结融合模型的评估脚本。
- `embedded/`：导出的端侧 C 推理模型与特征工程实现。
- `model/`：小型 IMU 运动门控参数及可复现附件。
- `results/`：训练或评估摘要，不含原始受试者数据。
- `docs/`：串行门控、训练和测试流程说明。

黄山派当前固件默认使用已验证的原型阈值事件链路以保证演示稳定。这里的融合模型需要先完成板端传感器采样率、窗口长度、特征顺序和单位对齐验证，才可替换为默认端侧推理实现。
