# IMU + EDA 模型指标与适用边界

本页汇总竞赛原型所用模型在公开数据上的严格实验结果。完整机器可读结果位于
`algorithm/imu_eda/results/strict_protocol/`；该目录不含任何原始受试者数据。

## 评估协议

- IMU 运动过滤：PAMAP2 wrist/hand IMU，S101--S106 训练，S107--S108 为未见受试者；
  2 秒窗口、1 秒步长。首 120 秒仅作个人基线，反馈与盲测按连续时间块分割，并保留隔离带。
- EDA / BVP：WESAD wrist 数据，S2--S9 训练，S10、S11、S13--S17 为未见受试者；
  5 秒窗口、1 秒步长。任务为公开数据中的 baseline 与 stress 二分类。
- 指标均为未参与阈值选择的盲测窗口汇总。它们不是跨日、跨会话或黄山派真实硬件上的性能声明。

## IMU 运动干扰过滤（部署候选）

该层的目标是识别剧烈运动并阻断后续 EDA 确认，不是情绪分类器。冻结全局阈值为
`p(high-motion) >= 0.22`；未见受试者盲测共 1,006 个窗口：

| 指标 | 结果 |
| --- | ---: |
| Accuracy | 84.19% |
| Balanced Accuracy | 88.60% |
| Precision | 62.32% |
| Recall | 97.68% |
| F1 | 76.09% |
| 混淆矩阵（TP / TN / FP / FN） | 253 / 594 / 153 / 6 |

高召回符合“尽量不让剧烈运动干扰进入生理判断”的保守目标，但 Precision 仍需通过真实手表
日常动作数据继续校准。实验中的个体阈值在不同受试者上并不稳定，因此当前不把它作为默认部署结论。

## WESAD 生理层与固定融合

下表为 7 位未见受试者、6,007 个盲测窗口的汇总结果。固定融合为 EDA 65% + BVP 35%，
仅用于离线对比：

| 模型 / 阈值 | Accuracy | Balanced Accuracy | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| BVP 全局阈值 | 34.18% | 43.34% | 36.00% | 86.43% | 50.83% |
| EDA 全局阈值 | 65.46% | 67.29% | 54.39% | 75.90% | 63.37% |
| 固定 65/35 融合全局阈值 | 70.33% | 70.93% | 60.03% | 73.74% | 66.19% |
| BVP 个人阈值 | 51.19% | 50.25% | 39.63% | 45.84% | 42.51% |
| EDA 个人阈值 | 77.46% | 77.91% | 68.22% | 80.04% | 73.66% |
| 固定 65/35 融合个人阈值 | 70.07% | 74.64% | 57.12% | 96.15% | 71.67% |

EDA 在该协议下优于 BVP。个人阈值可提高召回但也增加误报；不能只选取某一个指标宣称普遍提升。

## 黄山派 IMU → EDA 串行门控模块

`algorithm/imu_eda/embedded/mood_gate/` 是可编译的 C99 模块：IMU 以 100 Hz 输入、
2 秒窗口判断运动干扰；通过后 EDA 以 4 Hz 输入、5 秒窗口确认事件；确认后静默 30 秒。

该模块的 IMU 参数来自 PAMAP2，EDA 参数来自 WESAD。这两个数据集不是同一批受试者的同步采集，
因此**没有、也不能捏造端到端串行系统的 Accuracy、Precision、Recall 或 F1**。在接入黄山派时，
必须先完成真实 IMU 驱动、EDA 模拟前端到 uS 的标定，以及同步自采数据盲测；当前 `mood_gate_platform.c`
默认安全返回 `-ENOSYS`，不会伪造传感器数据。

## 可支持与不可支持的结论

- 可支持：IMU 可充当运动干扰过滤层；EDA 在上述公开数据和协议下优于 BVP；固定融合可作为离线基线。
- 不可支持：将 WESAD stress 等同于现实中的全部情绪激动；宣称个人阈值对所有人有效；将公开数据结果等同于真实黄山派硬件精度。
